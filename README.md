# KaramanbaTV

M3U / M3U8 IPTV oynatıcı (Samsung Tizen TV).

## Notlar
- Samsung Tizen TV'ye doğrudan `.wgt` dosyası yüklerken paketin **Samsung Author + Distributor sertifikası** (TV'nin DUID bilgisiyle oluşturulmuş) ile imzalanmış olması gerekir; aksi halde televizyon `Check certificate error` verir.
- TizenBrew üzerinden modül olarak çalıştırmak isterseniz depoyu GitHub'a yükleyip TizenBrew'de **Modüller > Modül ekle** üzerinden ekleyebilirsiniz.
